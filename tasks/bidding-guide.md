# 入札額の判断軸（本当のワールドカップ / GK）

過去8シーズンの落札データから導いた判断基準。`data/*__history.json` を根拠とする。
※ 分析時点: S9 の移籍市場（S1〜S8 が完了済み）

## 1. 相場は時系列で見る。全期間の平均は使わない

上乗せ額（落札額 − 評価額）の中央値は年々下落している。

| S3 | S5 | S6 | S7 | S8 |
|---|---|---|---|---|
| +14 | +12 | +9 | +7 | **+4** |

→ **参照は直近2〜3シーズンのみ。**

## 2. 過去の落札額は「必要額」ではない。競合の有無で意味が変わる

直近4シーズン（S5〜S8）の GK 95件:

| 区分 | 件数 | 上乗せ中央値 |
|---|---|---|
| 競合なし（単独入札） | **77件（81%）** | **+1** |
| 競合あり | 18件（19%） | +4 |

→ **単独入札の高額落札は相場ではなく「落札者の過払いの記録」。基準にしてはならない。**

例: S7 Petrovic 評価額14 → 21（+7、競合なし）は、15 で獲れたものに7を余分に払った記録。

## 3. 実務上の上限は「評価額 +2〜3」

競合が発生した場合でも、次点は評価額ちょうどであることが多い。

- S6 Sánchez: 評価額16、次点16、落札20
- S8 Verbruggen: 評価額15、次点15、落札20

→ **競合しても評価額+1〜2で決着する。それ以上は対抗が現れなければ丸損。**

## 4. 選手評価は直近シーズンを最重視

評価額（quotation）自体が直近成績を織り込んでいる。古い名声で判断しない。

例: Sánchez は評価額 16 → 13 に下落。2025-26 の成績低下（平均評点5.23、失点47）の反映。

## 5. 「売れ残り」で安全と判断しない

落札総数ではなく分布を見る。

| | S6 | S7 | S8 |
|---|---|---|---|
| GK 落札数 | 25名 | 24名 | 22名 |
| 獲得チーム | 10/10 | 10/10 | 10/10 |
| 大半のチーム | 2名 | 2名（8チーム） | 2名（8チーム） |

→ **全チームが必要数を確保して市場が閉じる。GK は出場枠が1つで代替が効かないため、取り逃しの損失は他ポジションより大きい。**

## 6. 競合が起きるのは「そのシーズンの上位選手」に限られる

跳ねるのは Sels 39 / Areola 36 / Raya 31 の層のみ。評価額13前後は競合しても 13〜17 で収まる。

→ **狙う選手がその層か否かで積む額を変える。**

## 7. 全枠を競り勝つ必要はないが、最低確保数は死守する

3枠狙いでも最低2名は確保しないと運用が成り立たない。優先順位を決め、主軸に厚く、保険は最小限の上乗せに留める。

## 適用例（S9 の GK 3枠）

| 選手 | 評価額 | 当初の札 | 推奨 | 適用軸 |
|---|---|---|---|---|
| Djordje Petrovic | 15 | 19 | **17〜18** | 軸2（前回21は競合なしの過払い）、軸3 |
| Bart Verbruggen | 16 | 17 | **18〜19** | 軸3、軸5・6（直近で唯一の実競合、評価額最高） |
| Robert Sánchez | 13 | 13 | **14〜15** | 軸3、軸4（評価額低下は成績反映） |

合計 49 → 49〜52。

## 分析の再現方法

```sh
# 競合の有無で層別した相場
node -e "
const fs=require('fs');
const rows=[];
for(const f of fs.readdirSync('data').filter(f=>/PHDHUA3Z_[5678]_/.test(f))){
  const j=JSON.parse(fs.readFileSync('data/'+f,'utf8'));
  for(const players of Object.values(j.mercato||{}))
    for(const p of Object.values(players)){
      if(p.position!==1||!p.wonBid) continue;  // position: 1=GK 2=DF 3=MF 4=FW
      rows.push({over:p.wonBid.price-p.quotation, contested:(p.lostBids||[]).length>0});
    }
}
const med=a=>{const x=[...a].sort((p,q)=>p-q);return x[Math.floor(x.length/2)];};
for(const c of [false,true]){
  const g=rows.filter(r=>r.contested===c);
  console.log(c?'競合あり':'競合なし', g.length+'件', '上乗せ中央値 +'+med(g.map(r=>r.over)));
}
"
```
